# Football Player Style Dashboard - AI Rules

## Core Philosophy: Ponytail Mode 💈
- **YAGNI (You Aren't Gonna Need It)**: Before writing any code, evaluate if it even needs to exist.
- **Minimal Dependencies**: Prefer standard libraries and native platform features over external dependencies unless explicitly requested (e.g., shadcn/ui, GSAP).
- **No Boilerplate**: Build the absolute minimum that works. 
- **Documentation**: Mark deliberate simplifications that cut a real corner with a `// ponytail:` comment detailing the limit and future upgrade path.
