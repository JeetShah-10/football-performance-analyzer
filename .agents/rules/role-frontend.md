# Frontend Lead Rules (Member 3)

## Scope
- Focus Area: `frontend/`
- Branch: `feature/react-ui`

## Guidelines for Antigravity AI
- **UI Quality**: Build a premium dashboard using Tailwind CSS, `shadcn/ui`, and smooth GSAP/Framer Motion animations.
- **Interactive Visualizations**: Use Plotly or Recharts for scatter plots and radar charts.
- **API Consumption**: Fetch data strictly from the FastAPI backend (default `http://localhost:8000`).
- **No Mocks in Prod**: Handle loading skeletons and error states cleanly when backend is unreachable.
