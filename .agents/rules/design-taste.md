# Anti-Slop & Design Taste Rules

Refer to the primary [DESIGN.md](../../DESIGN.md) document in the project root.

## Core Directives for Antigravity AI
1. **NO Vibecoded Gradients:** Absolute ban on neon purple/indigo gradients and centered outer glows.
2. **NO Pure Colors:** Use Charcoal / Zinc scale (`#0b0f17` background, `#f9fafb` text).
3. **NO Fake Copy:** Never write "Lorem Ipsum" or generic "Unlock your potential" fluff. Use actual football analytics terms.
4. **Strict SEO & Accessibility:** Single `<h1>`, unique page titles, clean console log, `alt` text on images, `<html lang="en">`.
